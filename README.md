# Anha & Sabeeh — Wedding Reception Invitation

Static site (vanilla HTML/CSS/JS). Edit `config.js` for details; open `index.html` or deploy the folder as-is.

When you deploy, replace `https://anha-sabeeh.vercel.app/` in the `og:`/`twitter:` meta tags of `index.html` with your real URL so WhatsApp previews load `og.jpg`.
